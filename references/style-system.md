# 两套精致风格，共用同一套内容与交互

支持现有paper（温暖纸本）与frosted（轻透磨砂）。用户已选风格就沿用；未选时一次说明两者供选择。用户明确要两套对照时，对同一source分别用--skin paper/--skin frosted构建，保留完整离线目录，可附两个独立HTML。普通任务交付用户所选风格。

| 维度 | paper 温暖纸本 | frosted 轻透磨砂 |
| --- | --- | --- |
| 主色 | 珊瑚红封套、奶白纸、黄与薄荷点缀 | 雾绿、蓝灰、荧黄、杏橙 |
| 页面材质 | 麻布底、实体纸层、书脊与缝线 | 渐变色域、通透面板、玻璃边缘 |
| 标题 | 宋体气质、舒展、温柔 | 无衬线粗标题、清晰、现代 |
| 导航 | 纸签与压边 | 圆润胶囊与荧黄选中态 |
| 照片 | 相纸轻斜、纸胶带或金属夹 | 亚克力相框、透明胶带或银色夹 |
| 年历 | 日格在前、相纸在后 | 照片在前、日格在后，像收藏柜 |
| 来信 | 信纸纹、邮票角饰、纸条愿望 | 柔光玻璃卡、圆形印记、浮层愿望 |
| 音乐 | 木质唱片机 | 杏橙色现代唱片机 |
| 分享长图 | 纸纹、相纸、胶带与暖墨 | 柔和渐变、圆角、银色夹与深绿墨 |
| 翻页 | 纸页折影、实体书感 | 卡页翻面、轻反光和通透阴影 |

结构、数据、来源、安全文本渲染、照片完整适配、年历、可编辑计划、分页和音效流程复用。不得复制两份应用逻辑。experience.css负责共用结构，paper.css校准纸本示例的珊瑚红与明亮纸层，frosted.css只覆盖磨砂视觉，motion.css统一阅读适配与动作。share.js按同一数据和两套配色/字体/相框绘图。

两个版本都必须精致。磨砂不是纸本换个背景，至少在字体、材质、边框、导航、照片、年历顺序、来信、音乐和分享图形成明确差异；相同的照片与文字不因换风格改成虚构内容。装饰不得盖主体和文字，不把磨砂做成裸图或大白卡，也不把纸本堆成泛黄脏纸。

分别验收桌面/手机、初始小屋、全部回看页、年历、长卷、来信和分享PNG。并排截图比较，核对内容/来源一致而风格明显不同；不要只比较body背景颜色。

开发后按[视觉验收](visual-acceptance.md)实际打开和对照。纸本总览补有来源的年份/照片小片段，磨砂用高亮小节点；年度摘要合入年历开头。

完整封面左侧均有照片/开场白/有据画像。纸本右侧是标题与胶带年份小相纸，磨砂右侧是大字导语、荧黄年份卡与通透小记；区别在材质、层级和图文组织，内容来源相同。
