# 微博交付验收

## 数据与内容

- 目标主页及UID不是登录账号的自动替代。按用户指定范围或默认十年，日期与时区一致；查3条不同年份的ID、原文、全文、多图数量和来源。
- 模式明确：selected或full。精选可按月分散、不只高赞或纯随机，年度不足实报；完整模式覆盖缺口说明，不拿样本声称全量。早年访问受限不能凑数。
- 分别核对扫描、保存和入选数。未读/失败/未选不写成没有发布；有明确可靠原创总量时才比较同口径总和，不能硬拿账号总发布数作分母。
- 每个主题、日期、歌曲依据可回查。总览≤200字，主题约40—100字，少资料减页。歌词、转述、节日和发文日期不误判为经历。
- 分享图、日历和总览都带实际范围与模式；不出现“全部”“从未”等无据结论。
- 图片属于完成条件：逐条核对源配图数，全部配图的双规格文件落地；未知数量不等于无图，4张代表图不能抵整份档案。有图、无图、超过9图分别对照源页核验，坏文件/远程URL/重复文件凑数不通过。执行 [图片完整下载与验收](images.md)，输出应收/实存数和缺口，不接受“图片后续再补”的完成版。

## 所选视觉要实际看

选择风格后先实际打开对应本地参考图，再检查1440×900和390×844下总览、三种主题、日历、计划，对照构图和层次。标题沿用用户选择。每张证据照片都可回到真实平台记录或用户授权素材，不能使用AI/卡通/图库替图；缺图有状态。桌面手机构图分别成立，导航不压内容，不把参考图铺成背景。

纸质风格：红奶白明亮、黑体可读、纸层贴纸有细节、装订纵向正确、手机先标题，不棕黄做旧。磨砂风格：背景透入、文字图清晰、高亮有面积、不变白卡长列表，没有复古装订。

## 功能实测

页面制作按 [页面框架说明](implementation.md) 构建。先运行`python scripts/audit_images.py 项目目录`；构建器和原检查器都会执行同一图片门禁。额外跑 `node --test scripts/test_framework.cjs`、`python -B scripts/test_build_journal.py` 与 `python -B scripts/test_audit_images.py`。这些通过仍不等于真实账号端到端或视觉通过。

- 计划首次打开已有根据记录生成的具体建议，而非空白新增表单；每条有来源，月份可修改。
- 日历默认实际有记录的月份，缩略图或短标题出现在对应日期；空月份不填假记录。1440×900、390×844均检查，无横向溢出、固定控件遮挡或装订空场。
- 已下载照片实际用于总览和有合适图片的主题；不能回看全部纯文字、照片只在日历。有图的主题按照片组织短记，文字主题保留原话与合适排版，不用其他事件照片充数。相册中全部配图能查看大图，不仅首页的几张。

1. 开头/中间/末页翻阅、目录直达、首尾禁用、切板块后位置保持。
2. 点有记录日期、无记录日期、未读日期、失败日期，状态正确；年月跳转与当日已收录内容一致。
3. 搜一个不在当前月份/年份的词，仍能命中；点击定位原文高亮并返回主题。
4. 点开缩略图看真实大图，缺图和断链有状态；原文/歌曲外链需网络，不声称完全离线。
5. 新建、编辑、删除一条测试计划，刷新恢复；导出备份、导入同ID冲突，手动版本保留；用备份恢复，不丢现有计划。
6. 断网/禁外网后以file://打开整个目录，浏览、搜索、日历、计划可用；不能只在localhost测试就宣称双击可用。
7. 真下载1080×1440PNG，文字完整、背景正确、来源同一数据、隐私默认关闭，不是用占位图假装导出。
8. 以一个断点续跑，不重复记录；扩大范围不覆盖旧资料；图片缺失可独立补。

## 交付边界

运行本地检查工具并保留简短结果；再记录实际浏览器测试。未测项明确写出，不将结构通过当全功能通过。不上传用户资料或对外发送，除非当前任务另外明确授权。
