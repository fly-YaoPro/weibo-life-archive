# 模板修改后的视觉回归

> 仅供用户另行要求模板调试时参考。普通制作仅执行[首图最小验收](scene-hotspots.md)，不要求全站重型浏览器验收；以[静态交付检查](acceptance.md)为准。

普通制作使用[成品验收](acceptance.md)。本文件用于模板/样式修改或视觉缺陷修复，按[维护边界](implementation.md)执行：打开最新构建→截图对照→记录差距→修源重建→复查受影响项。

可用visual_review、check_flip及其他专项脚本，传实际--browser-executable；没有自动化依赖时用宿主浏览器完成相同动作。图片naturalWidth>0和字体ready后截图，排除折叠details中的不可见元素。首次入册必须真实点击，不只访问#review。

| 检查面 | 重点 |
| --- | --- |
| 桌面/手机/中宽/短横屏 | 全部内容可读、无横向溢出、封面画像续页完整 |
| 首屏 | 完整原画、全部热点/控件可达、无浮层出屏 |
| 翻页前/中/后与反向 | 页片排版不变、无透字/镜像/重复书脊、落页一致 |
| paper/frosted | 内容同源，字体/材质/相框/导航/分享风格明显不同；不得仅换背景 |
| 年历/来信/分享PNG | 实际照片完整、标题不拆词、长文不截断、分段接缝和页尾正常 |

只比较本次风格对应的[参考图](case-effects.md)。图中的人物、日期、文字和已弃用按钮不能恢复到真实任务。模板复用并不免除检查生成图质量、图文来源和实际听感。

记录产物路径、实际视口、截图和修复结论；不能用旧图或CSS属性变化证明画面已正确。打包后与线上交付按[静态交付检查](acceptance.md)完成，仅补[首图最小验收](scene-hotspots.md)，不要求全站重型测试。
